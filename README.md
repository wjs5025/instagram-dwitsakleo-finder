# 뒷삭러 찾기 for Instagram

내가 팔로우하는 사람 중 나를 팔로우하지 않는 사람("뒷삭러")을 찾아 대시보드로 보여주는 개인용 도구입니다.

## 동작 방식

인스타그램 내부 API를 직접 호출하지 않고, **실제 화면(내 프로필의 팔로워/팔로잉 팝업)을 열어 마우스로 스크롤하며 화면에 보이는 목록을 읽어옵니다.** 사람이 직접 브라우징하는 것과 유사한 방식이라 API를 직접 두드리는 방식보다 차단될 위험이 낮습니다. 팔로우/언팔로우 등 계정을 변경하는 동작은 전혀 하지 않으며, 읽기 전용입니다.

## 주의사항

- 인스타그램 약관은 자동화된 접근을 금지하고 있어, 이 도구를 쓰다가도 계정에 일시적 로그인 확인(체크포인트)이 걸릴 수 있습니다.
- 같은 계정으로 너무 자주(예: 몇 분 간격으로 반복) 실행하면 차단/제한 위험이 커집니다. 하루 한두 번 정도로 사용하는 걸 권장합니다.
- 계정 규모가 크면 스크롤에 시간이 걸립니다 (팔로워/팔로잉 각각 수백 명 기준 1~2분 내외).
- 인스타그램 웹 화면 구조(라벨, 레이아웃)는 예고 없이 바뀔 수 있어 스크립트가 작동하지 않게 될 수 있습니다. 실패하면 `data/debug/` 에 실패 시점의 스크린샷과 화면 텍스트가 저장되니 원인 파악에 참고하세요.

## 사용법

```bash
npm install
npm start
```

명령 하나로 대시보드가 브라우저에서 자동으로 열립니다. "시작하기"를 누르면:

1. 설치된 Google Chrome이 열립니다 (최초 1회, 또는 세션 만료 시 인스타그램 로그인 필요).
2. 로그인을 감지하면 자동으로 프로필 페이지로 이동해 팔로워 → 팔로잉 순으로 화면을 스크롤하며 수집합니다.
3. 수집이 끝나면 같은 화면에 맞팔 안 하는 사람 목록이 바로 표시됩니다.

Google Chrome이 설치되어 있지 않다면 `npx playwright install chromium` 을 먼저 실행하세요.

로그인 세션은 `.auth-state.json` 에 저장되어 다음 실행부터는 이미 로그인된 상태로 바로 수집이 시작됩니다.

다른 계정을 확인하고 싶으면 대시보드 하단의 "다른 계정으로 로그인 (로그아웃)"을 누르세요. 저장된 로그인 세션과 이전 결과가 삭제되고, 다시 "시작하기"를 누르면 새 계정으로 로그인할 수 있습니다.

## 구조

- `server.mjs` — 로컬 대시보드 서버 겸 전체 흐름(로그인 확인 → 로그인 대기 → 팔로워 수집 → 팔로잉 수집 → 비교)을 관리하는 상태 머신
- `browser.mjs` — Chrome 실행, 로그인 세션(storageState) 저장/복원
- `sync.mjs` — 프로필 페이지에서 팔로워/팔로잉 팝업을 열고 스크롤하며 목록을 수집하는 로직
- `ui/` — 대시보드 페이지 (정적 HTML/CSS/JS)

## 데이터

`data/not-following-back.json` 에 마지막 결과가 저장되어, 서버를 재시작해도 대시보드에 바로 표시됩니다. `data/`, `.auth-state.json` 은 개인 정보/로그인 세션을 담고 있어 git에 커밋되지 않습니다 (`.gitignore` 참고).
